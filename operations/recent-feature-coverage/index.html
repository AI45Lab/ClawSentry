    最近功能文档覆盖矩阵¶

    本页用于回答一个运维读者最常见的问题：changelog 里提到的新能力，我应该去哪里理解、配置、验证？

    覆盖口径

    本矩阵只记录已在当前实现中存在的功能与文档入口。v0.6.1 后配置入口以 CS_* / AHP_*、clawsentry start、clawsentry config show --effective 和显式 --env-file 为准；.clawsentry.env.example 只是可提交模板，本地 env 文件只作为显式 runtime input 或 legacy migration surface。
