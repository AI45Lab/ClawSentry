# 更新日志

本页只保留公开使用者需要看到的发布摘要。详细开发记录和内部进度说明保留在开发仓库文档中。

## v0.7.1

- 公开发布面与公开仓库可复验内容对齐，在线文档、PyPI 主页和 GitHub README 使用一致的版本与测试计数。
- API 文档、配置页和首页刷新到当前公开版本。
- Benchmark 模式的用户说明保留在 [Benchmark 模式](operations/benchmark-mode.md)。
